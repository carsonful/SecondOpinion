Self-hosted font assets

These unmodified WOFF2 subsets replace the application's Google Fonts requests.
Comfortaa supports weights 500–700; Homemade Apple uses weight 400. The browser
loads only subsets needed for displayed characters. font-display: swap preserves
the previous fallback behavior; the two Latin files are preloaded in index.html.
